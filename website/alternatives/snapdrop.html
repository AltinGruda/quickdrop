File transfer that doesn't need you to fight the browser.

Snapdrop and PairDrop are clever: they move files between browsers with no app at all. The catch is they rely on the browser's WebRTC, which can break on big files, ad-blockers, VPNs, or picky networks.

QuickDrop keeps the no-install-on-the-phone idea but runs the receive side as a native desktop app. Files land in your Downloads folder, verified complete, no browser tab to babysit.

Why a native receiver beats a browser tab

Snapdrop and PairDrop are browser-to-browser, which is elegant until something in that chain disagrees:

  • No WebRTC to break. The receive side is a local app that owns the transfer end to end, so browser quirks can't stall it.
  • Nothing on the phone. You still just scan a code and pick files. No app on the sending side.
  • Verified, complete saves. A file is checked before it appears, so a "sent" file is a whole file.
  • Resumes, doesn't restart. Lock the phone mid-send and it picks up, not starts over.

Frequently asked questions

Do I have to install anything on my phone?

No. You scan a code with your phone's camera and the browser opens a page to pick files. Nothing to install.

Why is a desktop receiver more reliable than a browser?

Browser transfers (WebRTC) depend on the browser behaving and the network cooperating. A native receiver runs as a normal local app and is the sole owner of the transfer, so it avoids the connection issues that can crop up in a browser tab.

Can it handle large videos?

Yes. There are no file size limits, transfers stream rather than loading into memory, and files only appear once fully transferred.

Is QuickDrop free?

Yes, it's free on Windows 10, Windows 11, and macOS. No account needed.

Do files go over the internet?

No. Transfers happen directly between your phone and computer over your local network.
